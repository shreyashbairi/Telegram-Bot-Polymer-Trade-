# =====================================================================
#  POLYMER NAME NORMALIZATION  (grade folding)
# =====================================================================
#  Each block declares ONE canonical grade. Every spelling of that grade —
#  with any vendor, producer, type-prefix or quality/tier wording — is
#  stored and shown under the canonical name.
#
#  NORMAL GRADE  (the number is unique to one grade)
#  -------------------------------------------------
#    [Original Name]
#    0120
#
#  Listing just the number folds EVERY name that contains it as a whole
#  number: 0120, F0120, F-0120, Shurtan 0120, ANALOG F-0120 ... -> 0120.
#
#  AMBIGUOUS GRADE  (the same number is used by another grade)
#  -----------------------------------------------------------
#  e.g. "456" is used by both the Py-456 and the By-456 families. To fold
#  ONLY one of them, list the prefixed code under [Alternative Names]; then
#  the bare number is NOT matched on its own:
#    [Original Name]
#    456
#    [Alternative Names]
#    Py456
#  -> Py456 / P-Y456 / PY 456 fold to 456, while BY456 stays separate.
#
#  NOTES
#  -----
#    * Percentages ("30% TiO2") are never read as a grade number.
#    * Leading zeros matter: 030 and 30 are different grades.
#    * Lines starting with #  are comments. Blank lines are ignored.
#    * Re-read automatically on change. To re-label existing rows, run:
#          python apply_normalization.py
# =====================================================================
